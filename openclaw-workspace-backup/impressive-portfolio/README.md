# Impressive Professional Portfolio

A modern, interactive portfolio website with stunning animations and a professional design.

## Features

- **Modern Design**: Clean, professional layout with gradient accents
- **Responsive Layout**: Works perfectly on all devices
- **Smooth Animations**: Scroll-triggered animations for visual appeal
- **Interactive Elements**: Hover effects and smooth transitions
- **Professional Sections**: About, Projects, and Contact sections
- **Font Awesome Icons**: Modern vector icons
- **Google Fonts**: Beautiful typography with Poppins and Montserrat
- **Glassmorphism Effects**: Modern navigation with blur effect

## Technologies Used

- HTML5
- CSS3 (with advanced features like gradients, animations, and grid layouts)
- Vanilla JavaScript (for scroll animations)
- Font Awesome (icons)
- Google Fonts (typography)

## Sections

- **Hero Section**: Eye-catching introduction with animated background
- **About Section**: Personal information with skills tags
- **Projects Section**: Interactive project cards with hover effects
- **Contact Section**: Contact form with social media links
- **Navigation**: Fixed header with smooth scrolling

## Setup

To view this portfolio locally:

1. Clone or download this repository
2. Open `index.html` in your browser
3. Customize the content with your information

## Customization

To personalize this portfolio:

1. Replace the placeholder name in the hero section
2. Update the about section with your bio and skills
3. Add your actual projects with descriptions
4. Update contact information and social media links
5. Change colors by modifying the CSS variables in the `<style>` tag

## Deployment

This portfolio can be easily deployed to:

- Any static hosting service
